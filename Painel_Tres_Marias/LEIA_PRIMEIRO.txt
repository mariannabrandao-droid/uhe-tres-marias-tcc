ABRIR NO WINDOWS
Extraia este ZIP inteiro. Abra a pasta Painel_Tres_Marias e execute
INICIAR_WINDOWS.bat com duplo clique.
A primeira instalação precisa de internet. Mantenha o terminal aberto.
O inicializador instala truststore e as demais dependências no mesmo ambiente.

PUBLICAR NO GITHUB E STREAMLIT
Envie todos os arquivos de dentro da pasta Painel_Tres_Marias para a raiz
do repositório. Inclua dados_painel.zip como arquivo ZIP.
No Streamlit, selecione a branch main e o arquivo app.py.
Se enviar a pasta inteira preservando seu nome, indique
Painel_Tres_Marias/app.py como caminho principal.

As pastas de imagens e dados estão dentro de dados_painel.zip.
O aplicativo disponibiliza esses arquivos automaticamente na inicialização.
O limite de arquivos no envio ao GitHub se aplica ao pacote antes da execução.
O código mantém as figuras, os recortes e os cálculos da edição alinhada ao TCC.
